## 一、技术栈与产物

- **框架**：React 18 + TypeScript + Vite 5
- **UI**：TailwindCSS 3（内容展示/编辑页）+ Ant Design 5（管理/配置页：素材库、人设）
- **路由**：react-router-dom 6
- **状态/JWT**：React Context（AuthContext 持有 JWT、FlowContext 串联核心闭环）
- **构建产物**：`frontend/dist/`（静态资源，可由 Nginx 托管）

页面清单（计划书 4.4「页面与组件规划」）：

| 路由 | 页面 | 技术 | 对应模块 |
|---|---|---|---|
| `/materials` | 素材库管理（导入/打标/检索/分块预览） | Ant Design | F1 |
| `/hotspots` | 热点看板（领域筛选） | Tailwind | F1 |
| `/topics` | 选题列表（生成/一键选用） | Tailwind | F2 |
| `/generate` | 文案生成与对比编辑（SSE 多版本/编辑/优化） | Tailwind | F3/F4 |
| `/adapt` | 平台适配预览（分平台/导出/发布备注） | Tailwind | F5 |
| `/persona` | 账号人设配置 | Ant Design | F6 |

## 三、本地开发运行

### 1. 启动后端（M3，端口 8000）
```bash
cd <项目根>
python -m venv venv && source venv/bin/activate   # 或已存在的 venv
pip install -r api/requirements.txt
python db/init_db.py --reset        # 首次/重置：建库 + platform_rules 种子
python data/clean_chunk.py          # 播种演示素材/热点/账号 demo_seed
python -m uvicorn api.main:app --host 127.0.0.1 --port 8000
# 健康检查：http://127.0.0.1:8000/api/health
```

### 2. 启动前端（端口 5173）
```bash
cd frontend
npm install
npm run dev
# 打开 http://127.0.0.1:5173
```
> 开发服务器已将 `/api` 反向代理到 `http://127.0.0.1:8000`，无需手动处理 CORS。
> 演示账号：`demo_seed` ／ `Demo@2026`。

### 3. 离线演示（Mock）模式（无需后端）
当前端 `.env` 设 `VITE_USE_MOCK=true` 时，`src/api/client.ts` 会改为调用 `src/api/mock.ts` 的内存模拟数据，覆盖 `auth/hotspots/materials/persona/topics/copy(SSE生成·优化·适配)/export` 全链路；登录接受任意账号，生成走模拟 SSE 流式。布局顶部会出现「演示模式」黄条。适用于纯 UI 预览或后端未就绪时演示。**接真实后端时设为 `false` 并重启 `npm run dev` 即可切换。**

## 四、生产构建与部署（Nginx）

### 1. 构建静态产物
```bash
cd frontend
npm install
npm run build          # 输出到 frontend/dist/
```

### 2. Nginx 配置（反向代理 + 静态托管）
```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态资源
    location / {
        root /path/to/frontend/dist;
        try_files $uri $uri/ /index.html;
    }

    # 后端 API（与开发代理等价）
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        # SSE 流式需要关闭缓冲
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 300s;
    }
}
```
> **注意**：SSE（`/api/copy/generate`）必须关闭 `proxy_buffering`，否则前端收不到逐条 `data:` 事件。
> 生产环境请将 `api/config.py` 的 `CORS_ORIGINS` 收紧为前端域名（当前默认 `*`）。

## 五、核心闭环验证（计划书 5.2.4 T4.4）

在浏览器中依次走通：
1. **热点看板**：按领域筛选热门话题。
2. **选题列表**：点「生成选题」→ 卡片出现 → 「一键选用」自动带入生成页。
3. **文案生成对比**：选目标平台 → 「一键生成 N 版本」→ SSE 流式逐条产出 → 可逐段编辑 / 「风格优化」。
4. **平台适配预览**：自动带出任务 → 分平台 Tab 预览（标题/字数/标签/排版/发布备注）→ 导出 txt/docx。
5. **账号人设**：配置默认定位/口吻/领域，作为生成上下文。

验收标准（计划书）：主流浏览器最新两版本可用；核心闭环可演示。

## 六、与 M3 后端的对接约定（前端须遵守）

- **平台码**：前端发送 `weixin` / `xhs` / `douyin`（对应 `platform_rules.platform`），展示名「微信公众号 / 小红书 / 抖音」。
- **鉴权**：所有业务端点带 `Authorization: Bearer <token>`（登录/注册返回 `access_token`）。
- **选题无 GET 列表**：选题在「生成」后由前端缓存展示（后端仅提供 generate/select）。
- **SSE**：`POST /api/copy/generate` 返回 `text/event-stream`，事件类型 `start/retrieved/version/done/error`。
- **导出**：`POST /api/export` 直接返回文件流（非 JSON），前端按 `content-disposition` 触发下载。
- **M4 新增后端接口**（联调补齐，计划书 4.4 要求的「分块预览」「发布备注」）：
  - `GET /api/materials/{id}/chunks` —— 素材分块预览（只读，返回解密分块）。
  - `POST /api/copy/{task_id}/adapt` 响应项新增 `note` 字段 —— 平台发布备注。

## 七、已知限制

1. **暂无 GET 选题/版本列表接口**：选题与版本依赖前端流转态，刷新页面后需重新生成（不影响演示闭环；如需持久化可后续补 GET 端点）。
2. **离线 Mock 文案**：未配置真实 LLM 时，生成内容为模板化文案（同 M3），用于打通链路与演示。
3. **Tailwind + AntD 共存**：已关闭 Tailwind `preflight` 并统一主题色，避免样式冲突。
4. **移动端**：采用响应式栅格适配窄屏，但未做独立移动端交互优化。
