## 1. 架构总览（B/S 分层）

采用前后端分离的 B/S 架构，整体分为四层：

```mermaid

    subgraph 表现层["表现层（Web 客户端）"]
        FE[React + Tailwind / Ant Design<br/>素材库管理 · 热点看板 · 选题列表<br/>生成对比编辑 · 平台适配预览 · 账号人设配置]
    end
    subgraph 应用层["应用层（FastAPI）"]
        AUTH[JWT 认证]
        BIZ[业务逻辑 / 调度 API]
        SCHED[APScheduler 定时调度]
    end
    subgraph 算法层["算法层（LangChain 编排）"]
        ORCH[创作链路编排]
        RET[检索 + 重排]
        GEN[多版本生成]
        ADAPT[平台适配规则引擎]
    end
    subgraph 数据层["数据层（存储 + 外部模型服务）"]
        SQL[(sqlite3<br/>用户/素材/选题/版本/规则/统计)]
        VEC[(FAISS 向量索引<br/>素材分块向量)]
        LLM[LLM API<br/>OpenAI 兼容]
        BGE[BGE 中文向量模型]
    end
    FE -->|HTTPS REST / SSE| AUTH
    AUTH --> BIZ
    BIZ --> ORCH
    SCHED -->|热点采集| BIZ
    ORCH --> RET --> VEC
    ORCH --> GEN --> LLM
    ORCH --> ADAPT
    RET --> BGE
    BIZ --> SQL
    ORCH --> SQL
```

## 2. 请求流（同步创作请求）

```mermaid
sequenceDiagram
    participant U as 浏览器(React)
    participant A as FastAPI(认证/业务)
    participant O as LangChain 编排
    participant V as FAISS 检索
    participant L as LLM API
    participant D as sqlite

    U->>A: POST /api/copy/generate (JWT, 选题/平台/参数)
    A->>A: JWT 校验 + 参数校验
    A->>O: 触发创作链路(异步任务)
    O->>V: 语义检索素材 Top-5
    V-->>O: 相关素材 + 范例
    O->>L: 组装风格化提示词 → 生成 ≥3 版本(SSE)
    L-->>U: 流式返回版本片段
    O->>D: 落库 copy_tasks / copy_versions
    O-->>U: 完成(风格报告 + 替换建议)
```

## 3. 热点采集流（异步调度，与请求解耦）

```mermaid
sequenceDiagram
    participant S as APScheduler
    participant H as 热点采集器
    participant D as sqlite(hotspots)
    S->>H: 周期触发(每小时/每日)
    H->>H: 拉取源 + dedup_hash 去重
    H->>D: 写入/更新热点(is_active)
    Note over S,D: 失败重试，不阻塞用户交互请求
```

## 4. RAG 文案生成链路（核心）

```mermaid
graph LR
    T[选题] --> N1[选题节点: 结合热点+账号定位]
    N1 --> N2[检索节点: FAISS 召回 + 重排]
    N2 --> N3[生成节点: 风格模板+平台要求 → LLM ≥3 版本]
    N3 --> N4[优化节点: 语气/篇幅/口吻逐段重写 + 同质化抑制]
    N4 --> N5[适配节点: 平台规则引擎]
    N5 --> OUT[结构化多平台文案包 + 发布备注]
```

## 5. 分层职责说明

| 层 | 职责 | 关键技术 |
|---|---|---|
| 表现层 | 素材管理、热点看板、选题、生成对比、适配预览、账号人设配置；响应式 | React + Tailwind/AntD |
| 应用层 | JWT 认证、业务 API、APScheduler 调度 | FastAPI |
| 算法层 | 链路编排、检索重排、多版本生成、风格/平台适配 | LangChain |
| 数据层 | 业务库 + 向量索引 + 外部模型 | sqlite3 + FAISS + LLM/BGE |

## 6. 关键设计点
- **前后端解耦**：热点采集由 APScheduler 周期触发，与用户请求分离（计划书 3.1）
- **流式不阻塞**：长任务 SSE 流式输出，重任务后台调度（计划书 2.2.2）
- **向量主存储**：FAISS 承载分块向量，sqlite 存文本/元数据（计划书 4.5）
- **配置外置**：模型地址/采集源/平台规则可运维调整（计划书 2.2.5）
- **安全**：HTTPS + 字段加密 + 脱敏 + API Key 不入库（计划书 2.2.4）
- **外部依赖归类**：LLM API 与 BGE 为外部算法服务，置于「数据层」仅表示被算法层调用；二者为第三方/本地模型服务，非本系统存储，部署时需保证国内网络直连或镜像可用（计划书 2.3）
