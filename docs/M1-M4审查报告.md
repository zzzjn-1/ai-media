## 二、P1 · 领域词表跨产物不一致（已修复，功能性缺陷）

**问题本质**：项目内「领域」维度长期多头定义，且 M4 一度错配到 Mock 数据，导致真实后端联调时筛选再次失效。

| 产物 | 原领域定义 | 是否真实数据 |
|---|---|---|
| `docs/PRD.md` 1.2 | 科技 / 生活 / 财经 / 美妆 / 教育 | 含未落地项 |
| `frontend/src/api/types.ts` `DOMAINS` | 早期 `科技/生活/财经/美妆/教育` → M4 误改为 `AI技术/效率工具/内容创作/个人成长/职场/短视频` | ❌ 与真实库不符 |
| `frontend/src/api/mock.ts` | 6 个「AI 内容创作」领域 | ❌ 与真实库不符 |
| `data/corpus/*.txt` 文件名 | `科技/生活/财经`（54 素材，各 18） | ✅ 真实种子 |
| `db/app.db`（materials/hotspots 明文列） | `科技/生活/财经` | ✅ 真实种子 |
| `data/eval_set.json` meta.dimensions | `科技/生活/财经` | ✅ 真实种子 |
| `data/chunk_spec.md` / `data/评测方案.md` | `科技/生活/财经` | ✅ 一致 |

**实锤证据**：
- `python` 直查 `db/app.db`：`materials.domains` 去重 = `['生活','科技','财经','']`，`hotspots.domain` 去重 = `['生活','科技','财经']`。
- `data/corpus/` 文件名第二维（领域）统计：生活 18 / 科技 18 / 财经 18。
- `data/eval_set.json`：`meta.dimensions.domains = ['科技','生活','财经']`，总 108 条。

**修复**（已落代码 + 文档，复验通过）：
1. `frontend/src/api/types.ts`：`DOMAINS = ['科技','生活','财经']`。
2. `frontend/src/api/mock.ts`：素材/热点/人设/选题 Mock 数据全部重对齐（领域 `科技/生活/财经`、平台 `weixin/xhs/douyin`、风格 `专业/轻松/犀利`），保证 Mock 模式与真实后端行为一致。
3. `docs/PRD.md` 1.2：更正为「示例种子库含科技/生活/财经（美妆/教育可按需扩展）」。
4. `docs/M4交付说明.md` 第十节：修正原「统一为 6 个领域」的错误记录，如实记载该 bug 的来龙去脉与根治方式。

> 影响：此前所有页面（Hotspots 领域筛选、Materials/Persona 领域下拉、Topics 领域选择）均动态引用 `DOMAINS`，故修一处即全改；Mock 数据同步重对齐后，无论 Mock 还是真实后端，领域筛选均不再空白。
