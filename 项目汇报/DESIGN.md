# DESIGN.md · AI 自媒体内容创作助手项目汇报

## 0. 风格路由结论

场景 = 技术项目汇报（产品/工程答辩），**不命中**学术/咨询/红金三个垂直分支 → 走通用设计原则（universal-only），本文件即本项目设计宪法。

## 1. 画布与母版（具体 px）

- 画布：**1280 × 720**
- 页面 padding：上 20 / 下 20 / 左右 64
- **A · 标题块** 0–120px：主标题 34px bold #0F172A（左对齐，x=64），副标题 18px #64748B；标题左侧 6×34px 品牌渐变竖条
- **B · 内容区** 120–660px（可用 540px）：一切正文/图/卡，禁止挤占 A/C
- **C · 页脚条** 660–720px：左「AI 自媒体内容创作助手 · 项目汇报」14px #94A3B8 + 右页码 `NN / 14` 14px #94A3B8
- 封面（P01）/ 章节扉页（P03/P06/P09/P12）/ 结束页（P14）允许自定义版式并省略 C 区；其余内容页母版严格一致

## 2. 颜色系统（4 hex + 中性）

| 角色 | hex | 用途 |
|---|---|---|
| 主深色 | `#0F172A` | 封面/扉页/结束页背景、内容页标题文字、深色卡片 |
| 主色 | `#3B82F6` | 品牌渐变起点、强调数字、导航高亮、图表主系列 |
| 辅色 | `#06B6D4` | 品牌渐变终点、次级强调、图表第二系列、图标点缀 |
| 浅底 | `#F8FAFC` | 内容页页面背景 |
| 中性 | `#FFFFFF` / `#64748B` / `#94A3B8` / `#E2E8F0` | 卡片底 / 次级文字 / 页脚 / 边框 |

### 2.1 色彩面积分配（按页型）

| 页型 | 主深色 | 主色 | 辅色 | 强调用法 |
|---|---|---|---|---|
| Hero 封面/结束 | 60% | 15% | 10% | 渐变标题字 15% |
| 章节扉页 | 55% | 15% | 8% | 巨型编号渐变色 |
| 数据 Hero（P11） | 20% | 10% | 5% | **强调色爆发：巨型数字 #3B82F6 占 15–20%** |
| Supporting 内容页 | 12%（仅标题/深卡） | ≤8% | ≤5% | 强调 ≤5%，仅焦点元素 |

### 2.2 渐变与半透明（本项目声明）

- 品牌渐变：`linear-gradient(135deg, #3B82F6 0%, #06B6D4 100%)`——用于标题竖条、巨型数字、编号、卡片头部细条
- 深色蒙版：图片上叠 `rgba(15,23,42,0.55)` 保白字可读；内容页深色卡片 `#0F172A` 配白字
- 浅色卡片：`#FFFFFF` + `border: 1px #E2E8F0` + `boxShadow: 0 4px 20px rgba(15,23,42,0.08)`
- 半透明装饰：`rgba(59,130,246,0.08)` 大面积淡染（仅扉页/封面背景）

## 4. 信息密度门禁（本项目取值）

- 常规内容页留白 ≤ 35%；Hero 页留白 ≤ 45%（围绕锚点）
- 内容页正文 ≥ 180 字；卡片组每卡 ≥ 90 字，容器填充率 ≥ 85%
- 卡片尾元素（标签条/结论条）用 `marginTop: 'auto'` 钉底；同行兄弟卡三段等高对齐
- 每页 ≥ 1 视觉锚点（≥44px 元素或 ≥40% B 区主视觉）
