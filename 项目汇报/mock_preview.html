四项关键技术
每项技术都回答「是什么」与「解决什么」——不为技术而技术，指标可复测。
计划书 4.1 / 4.5 落地
RAG 两阶段检索
FAISS 粗排召回 40 条，规则重排叠加同领域 / 同风格先验取 Top-5 进入提示词。解决「素材找不准」：离线口径全量 180 条命中率 100%，消融显示重排贡献 +38.9pp。
LangChain LCEL 编排
提示词模板化组装与多版本解析走标准 Runnable，向量检索与重排保留自研以保证可控与离线可跑。解决「链路不可复现」：离线 Mock 与生产走同一条编排路径。
字段级加密（Fernet）
素材正文 / 分块加密落库，密钥经环境变量与数据分离；用户口令 PBKDF2 哈希。解决「素材资产安全」：数据库文件外泄不泄露正文，且不影响检索与分块预览。
SSE 流式生成
生成进度、逐版本、完成事件实时推送，前端边收边渲染。解决「长任务等待焦虑」：离线链路单篇平均 0.10s，接真实 LLM 后同一协议可观测每一步耗时。

04
难点与应对
四个真实难点：词表不一致、索引陈旧、口径漂移、凭证失真——每个都有根因拆解与可验证的修复证据。
难点拆解与修复证据
不停留在「遇到困难」，每条都追到根因，并给出可复跑的验证结果。
现象 → 根因 → 修复 → 验证
① 领域词表跨模块不一致
前端 / Mock / 种子数据各写一份，筛选点选空白。修复：DOMAINS 唯一真源 + Mock 自动补全。验证：五领域筛选全量有数据，Mock 与真实后端一致。
② 索引陈旧致检索命中率 0%
重建数据库后复用旧 FAISS 索引（169 vs 270 向量），chunk 整体错位。修复：索引签名（数量 / 最大 id / 维度）校验，过期自动重建。验证：重启后 270 向量、命中率恢复。
③ 评测与生产口径漂移
评测脚本内嵌参数、自行拼装检索逻辑，数字失去证明力。修复：评测直接调用生产检索函数，参数同源。验证：全量 180 条 100%，消融 61.1% → 100%。
④ 演示凭证三处不一致
「INSERT OR IGNORE」使新口令常量从未生效，代码 / 页面 / 文档三个值。修复：常量对齐数据库并注明仅新库生效，口令哈希程序化核验。验证：代码 / 登录页 / 文档 / 数据库四端一致。
